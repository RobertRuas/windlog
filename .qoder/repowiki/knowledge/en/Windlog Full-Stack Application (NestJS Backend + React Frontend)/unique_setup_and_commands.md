Prisma migrations run via `npx prisma migrate dev --name <migration_name>`; Prisma client generated to `./generated/prisma` (Prisma v7 convention). Backend requires `DATABASE_URL` and `JWT_SECRET` environment variables validated at startup. CORS configured via `CORS_ORIGIN` env variable defaulting to `http://localhost:5173`. Swagger docs available at `/api/docs` with Bearer JWT auth pre-configured.
