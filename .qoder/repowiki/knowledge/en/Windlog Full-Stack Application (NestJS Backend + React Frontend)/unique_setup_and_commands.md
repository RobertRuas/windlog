Backend requires `DATABASE_URL` and `JWT_SECRET` environment variables validated at startup via `EnvironmentVariables`. Prisma client is generated into `prisma/generated/prisma` (Prisma v7); migrations run with `npx prisma migrate dev --name <name>`. Swagger docs are served at `/api/docs` with a redirect from `/api/docs` to `/api/docs/`. Frontend stores the JWT in `localStorage` under the key `accessToken` and expects the API base path `/api/v1`.
