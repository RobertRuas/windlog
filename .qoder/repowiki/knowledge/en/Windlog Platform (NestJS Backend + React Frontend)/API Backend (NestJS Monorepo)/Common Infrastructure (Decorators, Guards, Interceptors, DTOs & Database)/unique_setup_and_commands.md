Requires a generated Prisma client at `../../prisma/generated/prisma/client.js` (run `prisma generate`). The `EnvironmentVariables` class enforces fail-fast startup — missing or invalid `.env` keys prevent the app from starting. `LoggingInterceptor` depends on `SystemLogService` and `LogAction`/`LogSeverity` enums from `modules/system-log`, so those modules must be initialized before this interceptor is registered globally.
