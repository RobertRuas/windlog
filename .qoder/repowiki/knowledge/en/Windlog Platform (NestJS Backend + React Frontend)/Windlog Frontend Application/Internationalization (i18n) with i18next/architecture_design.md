Single entry point `index.ts` initializes i18next via the `initReactI18next` plugin, registering all locale resources under the `pt` language key. Translations are split into feature-scoped namespaces (`common`, `login`, `home`, `logs`, `settings`, `users`, `projects`) each stored as a separate JSON file under `locales/pt/`. The default namespace is `common` and fallback language is `pt`. New languages are added by importing their JSON files and extending the `resources` object; English is scaffolded as a commented placeholder. Components consume translations through the `useTranslation('namespace')` hook from `react-i18next`.
