Single-page component `SettingsPage.tsx` acts as a composition root: it wraps content in `AppLayout`, reads the i18n `t` function via `react-i18next`, and conditionally renders `AccountSection` (always) and `AdminSection` (only when the current user has an ADMIN role). Role detection is done inline by decoding the JWT payload from `localStorage.getItem('accessToken')`. Each section lives in its own file under `components/` and receives only the `t` translator prop — no state or API calls are handled here. The page is a presentational shell; all routing is delegated to `react-router-dom`'s `useNavigate` hook.
