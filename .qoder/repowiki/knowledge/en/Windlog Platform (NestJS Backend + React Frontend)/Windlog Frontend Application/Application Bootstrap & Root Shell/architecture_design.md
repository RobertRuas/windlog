Two-file bootstrap layer: `src/main.tsx` is the single entry point that creates a React 18 root via `createRoot`, wraps rendering in `<StrictMode>`, imports global styles from `index.css`, and mounts `<App />`. `src/App.tsx` is the composition root — it instantiates a `QueryClient` (staleTime 30s), renders a globally scoped `<Toaster position="top-right" richColors closeButton />`, then nests `<BrowserRouter>` with all route definitions. Routing uses `react-router-dom` `<Routes>/<Route>` with three reusable guard components (`ProtectedRoute`, `AdminRoute`, `AdminOrHRRoute`) that read `accessToken` from `localStorage`, check expiration via `isTokenExpired()`, auto-remove expired tokens, and redirect accordingly. Pages are imported directly from `@/pages/*` (including the WeeklyTimesheet pages). `src/index.css` is the global stylesheet importing Tailwind v4 via `@import "tailwindcss"`, Inter font weights from `@fontsource/inter`, and shared form primitive classes (`.form-input`, `.form-select`, `.form-textarea`, `.form-button-*`, `.form-label`). `src/vite-env.d.ts` references `vite/client` so Vite's built-in asset/type declarations are available project-wide.
