The module is the thin bootstrap layer for the Vite+React app. `src/main.tsx` is the single entry point that creates the React 18 root via `createRoot`, wraps rendering in `<StrictMode>`, imports global styles from `index.css`, and mounts `<App />`. `src/App.tsx` is the composition root: it instantiates a `QueryClient` (staleTime 30s), renders a `<Toaster position="top-right" richColors closeButton />`, then nests `<BrowserRouter>` with all route definitions. Routing uses `react-router-dom` `<Routes>/<Route>` with three guard components — `ProtectedRoute` (auth-only), `AdminRoute` (ADMIN role), and `AdminOrHRRoute` (ADMIN or HR) — each reading `accessToken` from `localStorage`, checking expiration via `isTokenExpired()`, and auto-logging out expired tokens. Pages are lazy-imported from `@/pages/*` and `/error` is the only public catch-all. `src/index.css` is the global stylesheet importing Tailwind (`@import "tailwindcss"`) and Inter font weights, plus shared form element classes (`.form-input`, `.form-select`, `.form-textarea`, `.form-button-*`, `.form-label`). `src/vite-env.d.ts` references `vite/client` so Vite's built-in asset/type declarations are available throughout the project.
