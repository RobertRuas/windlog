Single-page component `LogsPage.tsx` orchestrates data fetching via TanStack Query (`getLogs`, `getLogStats` from `@/services/system-log.service`) and composes four presentational components under `components/`: `LogFilters` (search + advanced filters), `LogStats` (summary cards), `LogTable` (paginated grouped table), and `LogRow` (expandable row with details). The page owns all client-side state (filters, expanded rows/groups) and groups consecutive logs sharing the same method+url+user key before rendering. Data layer is thin — only query keys follow the `['entity', filter?]` convention and polling uses `refetchInterval`. UI primitives come from shared `@/components/ui/Button`; layout comes from `@/components/layout/AppLayout`. All i18n keys are namespaced under the `logs` resource via `useTranslation('logs')`.
