Single-page feature rooted at `UsersPage.tsx` that composes three child components under `components/`: `UsersFilters` (search + role dropdown), `UsersTable` (paginated list with edit/reset/delete actions), and `UserModal` (create/edit form plus temporary-password display). The page owns all state (filters, pagination, modal visibility, form data, temporary password) and coordinates TanStack Query's `useQuery` for the user list and four `useMutation` hooks (create, update, delete, resetPassword). All API calls go through `@/services/user.service`, which exports both functions and shared types (`UserListItem`, `CreateUserPayload`, `UpdateUserPayload`, `UserFilters`). The page is wrapped in `AppLayout` and gated by ADMIN/HR roles. Mutaions invalidate the `['users']` query key on success to keep the table in sync.
