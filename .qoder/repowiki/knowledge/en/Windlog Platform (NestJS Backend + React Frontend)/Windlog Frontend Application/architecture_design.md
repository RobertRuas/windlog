The application is bootstrapped in `src/main.tsx` (React 18 `createRoot`) which mounts the root `App` component. `App.tsx` is the single orchestrator: it creates a shared `QueryClient`, wraps everything with `QueryClientProvider`, `BrowserRouter`, and a global `<Toaster>`, then declares all routes guarded by three role-based wrappers — `ProtectedRoute` (authenticated), `AdminRoute` (ADMIN only), and `AdminOrHRRoute` (ADMIN or HR). Pages live under `src/pages/<feature>/` and consume typed services from `src/services/` (each service encapsulates axios calls for one domain). Shared building blocks are split into `src/components/ui/` (generic UI primitives like Button, Input, DataTable) and `src/components/layout/` (structural shell: AppLayout, Sidebar). Cross-cutting concerns — i18n (`src/i18n`), JWT helpers (`src/utils/jwt.ts`), file URL handling (`src/hooks/useFileUrl.ts`), and constants (`src/constants/`) — are imported globally by pages and services. All state mutations go through TanStack Query keys following the `['entity', filter?]` / `['entity', id]` convention, and every CRUD operation surfaces feedback via Sonner toast notifications.
