Single-page module rooted at `HomePage.tsx` which composes two main sub-components: `SummaryCards` for the dashboard overview and `ProfileCard` as a shortcut to `/profile`. All business logic for profile editing is delegated to specialized components under `components/`: `ProfileSection` provides a reusable inline-editable section with field configuration (`FieldConfig`, `FieldGroup`), `ProfileWizard` orchestrates a 5-step guided flow using state-driven step navigation, and `ProfileCompleteness` renders a progress bar + checklist driven by `@/utils/profileCompleteness`. Data fetching uses TanStack Query with the `['profile']` key pattern via `getProfile` from `@/services/auth.service`; mutations (`updateProfile`, `addPhone`, `addDocument`) are invoked directly within component handlers and invalidate related query keys (`['profile']`, `['notifications']`). The module depends on shared UI primitives from `@/components/ui/Button` and layout from `@/components/layout/AppLayout`, keeping all domain-specific presentation here.
