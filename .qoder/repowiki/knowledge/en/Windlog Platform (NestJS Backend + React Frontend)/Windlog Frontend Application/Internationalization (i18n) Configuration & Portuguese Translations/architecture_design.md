Single entry point `index.ts` initializes i18next via the `initReactI18next` plugin, importing all Portuguese JSON translation files and registering them under the `pt` language key in a flat `resources` object. Each feature page has its own namespace file (`common`, `login`, `home`, `logs`, `settings`, `users`, `projects`, `timesheet`) stored as separate JSON files under `locales/pt/`. The default namespace is `common` and fallback language is `pt`. Components consume translations through the `useTranslation('namespace')` hook from `react-i18next`. English is scaffolded as a commented placeholder block for future expansion.
