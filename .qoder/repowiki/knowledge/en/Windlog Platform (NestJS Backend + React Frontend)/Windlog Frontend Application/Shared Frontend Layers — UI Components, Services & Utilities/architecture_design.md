Five horizontal layers with strict one-way dependency direction: `components/ui/` (stateless presentational primitives like Button, Input, DataTable) → `components/layout/` (structural shells AppLayout + Sidebar that compose UI primitives and fetch user profile via TanStack Query) → `hooks/` (stateful logic such as `useFileUrl` wrapping TanStack Query calls) → `services/` (HTTP layer where every domain service imports the single `api.ts` fetch wrapper, unwraps the NestJS `{ data, message, statusCode, timestamp }` envelope, and exposes typed functions) → `utils/` (pure functions like JWT decoding/base64url parsing) → `types/` and `constants/` (shared interfaces and lookup tables). `src/services/api.ts` is the sole HTTP entry point centralizing JWT injection from `localStorage`, 401 auto-logout with a deduplication flag, and error handling; all domain services (`auth.service.ts`, `upload.service.ts`, `weekly-timesheet.service.ts`, etc.) wrap `api.get/post/put/delete/patch`. Layout components never contain business logic or direct API calls beyond query fetching. The weekly-timesheet service defines its own domain interfaces (`WeeklyTimesheet`, `TimesheetDay`, `TimesheetEntry`, `PaginatedResponse`) co-located with the service, mirroring the backend contract explicitly.
