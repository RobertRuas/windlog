Each subdirectory is an independent NestJS feature module exposing a `{name}.module.ts`, `{name}.controller.ts`, `{name}.service.ts`, and a `dto/` folder. Modules are wired through Nest's dependency injection: controllers only accept DTOs and delegate all logic to services; services own all Prisma queries via `PrismaService` from `../../database/prisma.service.js`. Cross-module dependencies are explicit — `AuthModule` imports `UploadModule` for avatar handling and depends on `NotificationService` for profile-completeness sync; `NotificationsModule` and `SystemLogModule` are marked `@Global()` so they can be injected anywhere without re-importing. The upload subsystem is a shared utility consumed by both `auth` and `projects` modules, configured through `multer.config.ts` which enforces category allowlists and MIME filtering. There is no cross-talk between sibling modules except through these shared services or the global modules.
