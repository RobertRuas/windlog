Two-layer application sharing a single Prisma schema as the authoritative data contract. The backend (API/) is a NestJS app bootstrapped via AppModule that registers global interceptors, filters, guards, and Swagger docs, then exposes six feature modules (Auth, Users, Projects, Notifications, Upload, System-Log) each following the strict {name}.module.ts + {name}.controller.ts + {name}.service.ts + dto/{name}.dto.ts pattern. The frontend (src/) mirrors this structure: pages under src/pages/ call typed services in src/services/ which wrap axios calls to the same endpoints, with TanStack Query managing cache keys using the ['entity', filter?] convention. Auth flows through JWT strategies on the backend and token storage on the frontend, while Prisma-generated types flow into both layers via shared DTOs and TypeScript interfaces. LoggingInterceptor maps HTTP requests to LogAction entries stored via the System-Log module.
