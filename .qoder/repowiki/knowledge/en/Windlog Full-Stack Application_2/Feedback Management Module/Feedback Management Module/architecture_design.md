Follows the standard NestJS module pattern: `feedback.module.ts` wires `FeedbackController`, `FeedbackService`, and `PrismaService`; controller exposes REST endpoints under `/api/v1/feedbacks` with JWT authentication via `AuthGuard('jwt')` and ADMIN-only routes guarded by `RolesGuard` + `@Roles(Role.ADMIN)`; all business logic lives in `FeedbackService` which uses `PrismaService` directly — no database access outside the service. DTOs in `dto/` define request validation with `class-validator` decorators and Swagger metadata. The module exports `FeedbackService` for reuse by other modules. Soft delete is enforced through `deletedAt: null` filters on every query.
