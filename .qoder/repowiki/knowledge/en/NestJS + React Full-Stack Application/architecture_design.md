The repository is split into two layers: `API/` (NestJS backend) and `src/` (React frontend). The backend root module (`API/src/app.module.ts`) wires all feature modules — Auth, Users, Projects, Upload, Notifications, SystemLog, WeeklyTimesheet — each following the strict `{name}.module.ts + {name}.controller.ts + {name}.service.ts + dto/{name}.dto.ts` pattern. The frontend root component (`src/App.tsx`) wires routes via React Router and exposes TanStack Query globally; each page mirrors a backend module and calls its service in `src/services/`, which wraps axios calls to the NestJS endpoints. Prisma schema under `API/prisma/schema.prisma` is the single source of truth for types consumed by both layers. Cross-cutting concerns are centralized: `API/src/common/` provides guards, interceptors, decorators, filters, and DTOs shared across all modules, while the frontend shares UI primitives under `src/components/ui/` and layout under `src/components/layout/`. Authentication flows through JWT stored in localStorage, with route guards protecting frontend pages and `roles.guard` / `current-user.decorator` protecting backend controllers.
