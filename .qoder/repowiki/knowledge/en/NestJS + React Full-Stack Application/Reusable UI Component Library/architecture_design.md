Flat collection of single-purpose functional React components under `src/components/ui/`, each exported as a named function with a dedicated TypeScript interface for props. Components are intentionally dumb/presentational — they receive data via props and emit callbacks (`onChange`, `onSave`, `onClear`, `onCancel`) rather than managing business logic. Cross-cutting concerns are delegated to hooks: `SecureFileLink` and `SecureImage` both consume `@/hooks/useFileUrl` to obtain temporary signed URLs, keeping the security boundary outside the UI layer. The `DataTable` is the most complex component, exposing a generic `<T>` column definition API (`DataTableColumn<T>`, `DataTablePagination`) so consumers drive rendering entirely through `render` functions. Styling is uniform across all components using Tailwind CSS utility classes with consistent spacing, border, and color tokens.
