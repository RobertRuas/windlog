Two cooperating React components: `FeedbackButton` renders a fixed-position circular FAB in the bottom-right corner (visible inside `AppLayout`) and toggles the `FeedbackModal`. `FeedbackModal` owns the full submission flow — category selection via pill buttons, title/description inputs, optional screenshot upload (drag-and-drop or click), and auto-collected technical context. Data fetching uses TanStack Query (`useQuery` for recent error logs, `useMutation` for creating feedback) and all API calls go through centralized services (`@/services/feedback.service`, `@/services/system-log.service`, `@/services/api`). Screenshot uploads are handled separately via `api.post('/api/v1/upload/feedbacks', formData)` before the main feedback mutation. The modal is controlled externally via `isOpen`/`onClose` props from the button, keeping state minimal and unidirectional.
