Three independent presentational React components under `src/pages/settings/components/`, each exported as a named function component accepting a single `t` translation prop. `AccountSection.tsx` and `AdminSection.tsx` are lightweight navigation cards built with Tailwind CSS and lucide-react icons, using `react-router-dom`'s `useNavigate` for routing to `/profile` and `/logs`. `MyFeedbacksSection.tsx` is the only data-bearing component: it fetches feedback via TanStack Query (`useQuery` with key `['my-feedbacks']`) from `@/services/feedback.service`, renders a single visible item plus a 'view more' button that opens a local `FeedbacksModal` showing all entries. Each file follows the same shape — JSDoc header describing purpose and props, a typed `Props` interface, and a default export of the component.
