Two-layer React structure under `src/components/feedback/` and `src/pages/feedbacks/`. `FeedbackButton.tsx` is a fixed-position floating trigger (bottom-right, z-30) that owns local open/close state and renders `FeedbackModal.tsx`, which encapsulates the full submission form: category pills, title/description inputs, image upload via `api.post('/api/v1/upload/feedbacks')`, technical context collection via `@/utils/technicalContext`, and automatic fetching of recent error logs through TanStack Query (`['recent-system-logs']`). Data mutations use `useMutation` calling `createFeedback` from `@/services/feedback.service`; read operations in the admin page use `getFeedbacks` and `getFeedbackStats` with query keys following the project convention `['entity', filter?]`. The `FeedbacksPage.tsx` is an ADMIN-only route wrapped in `AppLayout`, exposing a paginated table, collapsible filters (status/category/priority), a detail/edit modal, and soft-delete via `deleteFeedback`. All UI text goes through `react-i18next` with namespace `'feedback'`, and every mutation surfaces user feedback via `sonner` toast messages.
