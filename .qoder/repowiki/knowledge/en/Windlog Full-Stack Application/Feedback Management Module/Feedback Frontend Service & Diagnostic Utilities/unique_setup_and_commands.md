No build or setup commands are required. To use the console capture, call `startConsoleCapture()` before the operation you want to debug and `stopConsoleCapture()` afterwards; captured logs are retrieved via `getCapturedLogs()` and formatted with `formatCapturedLogs()`. The technical context is collected on demand via `collectTechnicalContext()` and can be rendered as a human-readable string with `formatTechnicalContext()`.
