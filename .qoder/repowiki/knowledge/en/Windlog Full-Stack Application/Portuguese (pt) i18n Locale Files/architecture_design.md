Flat JSON locale files grouped by feature domain (common, login, projects, users, settings, timesheet, logs, feedback, onboarding, home). Each file is a self-contained key-value map with nested objects mirroring UI component structure (e.g. `nav`, `buttons`, `status`, `modal`, `toast`, `errors`). The `common.json` file holds shared strings reused across all features, while domain-specific files like `projects.json` contain full CRUD messages including toast notifications, table labels, modal fields, and status enums. There is no runtime code — these are pure data files loaded at build/runtime by the application's i18n framework.
