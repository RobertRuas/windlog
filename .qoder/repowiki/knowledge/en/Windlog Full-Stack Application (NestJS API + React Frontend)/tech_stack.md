Backend: NestJS with Passport + JWT authentication, class-validator DTOs, Prisma ORM against PostgreSQL (Prisma v7 with `prisma-client` generator outputting to `./generated/prisma`), Swagger/OpenAPI docs at `/api/docs`, Helmet security headers, gzip compression. Frontend: React 18 with React Router v6, TanStack Query (React Query) for caching, Sonner for toast notifications, i18next with Portuguese locale files, Tailwind CSS for responsive mobile-first styling, Vite as build tool.
