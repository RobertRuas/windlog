Database migrations are run via `npx prisma migrate dev --name <name>` as documented in `schema.prisma`; Prisma client is generated to `./generated/prisma` per the generator config. Required environment variables include `DATABASE_URL`, `JWT_SECRET`, `JWT_EXPIRES_IN`, `CORS_ORIGIN`, and `PORT`. Swagger UI is available at `/api/docs` with a redirect middleware ensuring trailing slash.
