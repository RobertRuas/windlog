Backend requires `DATABASE_URL` and `JWT_SECRET` environment variables validated at startup in `app.module.ts`. Prisma migrations are run via `npx prisma migrate dev --name <name>` and the client is regenerated to `./generated/prisma` (not `node_modules`). Swagger UI is served at `/api/docs` with a redirect from `/api/docs` to `/api/docs/`. Frontend runs on port 5173 by default and expects the API at `CORS_ORIGIN` (defaults to `http://localhost:5173`).
