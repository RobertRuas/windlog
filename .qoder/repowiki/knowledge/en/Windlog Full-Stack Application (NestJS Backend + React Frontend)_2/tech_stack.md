Backend: NestJS with Passport JWT authentication, class-validator DTOs, Prisma ORM against PostgreSQL, Swagger/OpenAPI docs at `/api/docs`, Helmet security headers, compression middleware. Frontend: React + TypeScript with Vite, react-router-dom for routing, @tanstack/react-query for server state, Sonner for toast notifications, i18next with Portuguese locale JSON files, Tailwind CSS for responsive mobile-first styling.
