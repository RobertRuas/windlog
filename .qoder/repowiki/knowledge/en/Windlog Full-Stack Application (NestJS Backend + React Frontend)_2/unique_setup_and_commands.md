Database migrations are managed with Prisma v7: run `npx prisma migrate dev --name <migration_name>` after editing `schema.prisma`; the generated client is output to `./generated/prisma` (not `node_modules`). Environment variables `DATABASE_URL` and `JWT_SECRET` are required at startup and validated in `app.module.ts`. Swagger UI is served at `/api/docs` with a redirect from `/api/docs` → `/api/docs/` to fix relative asset paths.
